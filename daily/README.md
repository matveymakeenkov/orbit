# Ежедневный вызов

Каждый день одна головоломка, одинаковая для всех: «Пробка» или «Рикошет». Побеждает тот, кто решил её за меньшее число ходов. Неделя (Пн–Вс) считается по сумме очков.

Ссылка: https://matveymakeenkov.github.io/orbit/daily/

## Как включить вход и лидерборд (5 минут)

1. Зарегистрируйтесь на https://supabase.com и создайте проект **New project**. Подойдёт бесплатный план и любой регион, например Frankfurt.
2. **SQL Editor → New query**: вставьте целиком содержимое `setup.sql` и нажмите **Run**.
3. **Authentication → Sign In / Providers → Email**: выключите **Confirm email**, чтобы друзья входили сразу после регистрации. Встроенная почта Supabase отправляет всего несколько писем в час, поэтому с подтверждением регистрация будет буксовать.
4. **Project Settings → API Keys** (или кнопка **Connect**): скопируйте **Project URL** и **publishable key**. Подойдёт и старый **anon** key.
5. Вставьте их в `config.js`. Ключ публичный, хранить его в репозитории можно: доступ защищён правилами из `setup.sql`.

## Правила подсчёта

- Считаются все ходы: «отменить» и «сначала» возвращают фигуры, но не уменьшают счётчик.
- Очки за день = round(100 × лучшее возможное ÷ ваши ходы).
- Засчитывается первое решение за день. Записать результат можно только за сегодня (по Москве).

## Головоломки

`puzzles.js` содержит головоломки на год вперёд. Для каждой решатель нашёл минимальное число ходов. Сложность по дням: Пн — разминка, Вс — босс недели. Новый набор генерирует `gen.js`:

```
node gen.js <номер_дня> <сколько_дней> > puzzles.js
```
